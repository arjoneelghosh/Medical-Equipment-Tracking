# Medical Equipment Tracking

A medical-supplies catalog and inquiry platform built for browsing healthcare products, viewing specifications, and exploring category-wise inventory in a polished web interface.This project presents medical and hygiene products through a structured product-catalog flow with category navigation, search, product-detail pages, and contact pathways. It is best described as a **medical equipment catalog/storefront prototype** rather than a full backend inventory-tracking system.


## Overview

Medical product websites often present items in static brochure-like layouts that make it harder to browse categories, compare products, and inspect specifications in a structured way.

This project addresses that by building a frontend product experience around:

- category-driven browsing
- searchable catalog pages
- detailed product pages with specifications
- category segmentation across major healthcare supply groups
- inquiry/contact routing for quote and product information requests

The current implementation is focused on the **user-facing catalog layer**.

## Features

- Multi-page React application
- Product catalog with category filtering
- Search across product names and descriptions
- Detailed product pages with specifications
- Dedicated page for medical devices
- Structured product and category datasets
- Responsive healthcare-focused UI
- Floating chatbot component integrated into the app shell
- Contact and about pages for business-facing navigation


## Current Scope

The application currently functions as a **medical product catalog and inquiry interface**.

It includes:
- category browsing
- product discovery
- product detail inspection
- static specification rendering
- frontend routing and interface polish

It should be framed conservatively as a **catalog/storefront-style frontend prototype** unless stronger backend evidence is added for inventory management, order handling, or real tracking workflows.
